Security Layers

L1 — Edge: Vercel WAF, CSP headers
L2 — Rate: Upstash Redis per-IP
L3 — Auth: JWT + HttpOnly cookies
L4 — 2FA: TOTP (Google Authenticator)
L5 — RBAC: Role-based access control
L6 — Data: Encrypted at rest (NeonDB)
L7 — Audit: Full audit trail logging
